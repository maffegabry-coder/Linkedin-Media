# Strumenti grafici dei post

- `r2lib.py`: stile (colori, font, firma, griglia) e grafiche riutilizzabili.
- `render_ai.py`, `render_next.py`: esempi di caroselli da 6 slide (formula dei post).

Per usarli: `npm install @fontsource/space-grotesk @fontsource/manrope @fontsource/jetbrains-mono` in questa cartella,
salva la foto di Gabriele (dal brand kit, immagine con id "avatar") in `photo/avatar.png`, poi `python3 render_next.py`.
La foto non è in questo archivio pubblico.
